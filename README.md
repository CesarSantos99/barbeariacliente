# 💈 Site Profissional para Barbearias

Uma solução digital desenvolvida para barbearias que desejam fortalecer sua presença online, atrair novos clientes e facilitar o agendamento de horários.

🔗 **Demonstração online:** https://barbeariacliente.vercel.app/

## 📌 Sobre o projeto

Este projeto foi desenvolvido como um produto comercial, pensado para atender às necessidades de barbearias que desejam apresentar seus serviços de maneira profissional e oferecer mais praticidade aos clientes.

O site possui uma identidade visual moderna, navegação intuitiva e layout responsivo, proporcionando uma experiência agradável tanto em computadores quanto em dispositivos móveis.

## ✨ Benefícios para o negócio

- Fortalece a presença digital da barbearia.
- Apresenta serviços e preços de forma organizada.
- Facilita o contato e as solicitações de agendamento.
- Valoriza a imagem profissional do estabelecimento.
- Ajuda novos clientes a conhecerem a barbearia.
- Funciona em celulares, tablets e computadores.

## ⚙️ Funcionalidades

- Página inicial personalizada.
- Apresentação dos serviços.
- Exibição de preços e informações.
- Apresentação dos profissionais.
- Área de agendamento.
- Layout responsivo.
- Navegação simples e intuitiva.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel
